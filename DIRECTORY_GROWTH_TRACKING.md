## Review Rules

- If a channel sends visits but no signup clicks, improve the listing headline, screenshots, or category.
- If a channel sends signup clicks but no signup success, review the signup page and trust signals.
- If a channel sends signups but no resume creations, improve dashboard onboarding.
- If a channel sends resume creations but no upgrades, improve locked-feature prompts and Pro value.
- Skip paid directory upgrades until there is proof of signup quality.

## Listing Health Checklist

- Public page opens without login.
- Website link points to `https://www.rolearc.xyz` or the matching UTM URL.
- Logo is current RoleArc logo, not old CVForge branding.
- Short description says AI resume builder, not resume screening.
- Categories mention resume builder, career, job search, writing, AI tools, or productivity.
- Pricing is marked as free/freemium with paid Pro option where possible.
- Screenshots show the template gallery and builder, not only the homepage.
- No paid placement is active unless intentionally approved.

## What Counts As Worth Continuing

Continue with a channel if it produces at least one of these:

- Qualified referral traffic.
- Signup events.
- Resume creation events.
- Useful comments or product feedback.
- Search-visible backlink from a credible directory.

Pause or skip if it only creates admin work, paid upsells, or low-quality outreach.
